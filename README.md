BsCode turns one project into a coordinated multi-agent workspace.

- coordinate up to four Codex, Claude, or shell agents across local and SSH workspaces
- switch between terminal, Zen, Cinematic, and Pixel views without losing agent state
- share project files, notes, outputs, tasks, and handoffs from one desktop workspace
